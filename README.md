# Cybersecurity Operations & Analysis Portfolio

A repository containing hands-on security labs, detection engineering queries, and technical incident write-ups completed across Linux administration, SQL auditing, network traffic analysis, and Python automation.

## Structure
* **`01-linux-administration/`**: Permission hardening, file auditing, and bash log filtering.
* **`02-sql-security-queries/`**: Security database queries tracking anomalous logins and system updates.
* **`03-network-analysis/`**: Packet inspections with `tcpdump`/Wireshark and custom IDS rules.
* **`04-incident-response/`**: Incident journals, alert triage, and NIST SP 800-61 workflows.
* **`05-python-automation/`**: Automated log parsers, IP allowlist/blocklist managers, and security scripts.
